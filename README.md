# 🏃 Guia Simples de Corrida

## 📌 Sobre o Projeto

O **Guia Simples de Corrida** é um site desenvolvido como atividade da disciplina de **Interação Humano-Computador (IHC)**, com o objetivo de orientar pessoas interessadas em começar a correr ou melhorar seu desempenho.

O projeto apresenta três níveis de treinamento progressivos, permitindo que o usuário encontre orientações de acordo com seu nível de experiência.

## 🎯 Objetivo

Desenvolver uma interface simples, intuitiva e acessível, aplicando conceitos de usabilidade, experiência do usuário (UX), acessibilidade e responsividade.

## 💻 Tecnologias Utilizadas

- **HTML5:** Estruturação das páginas.
- **CSS3:** Estilização, organização visual e responsividade.
- **JavaScript:** Interatividade e funcionalidades de acessibilidade.
- **LocalStorage:** Armazenamento das preferências de acessibilidade no navegador.

## 🏃 Funcionalidades do Site

### Página Inicial
- Apresentação do guia.
- Escolha entre três níveis de treinamento.
- Orientações básicas para corredores.

### Nível 1 – Iniciante (5 km)
- Planilha de treinamento de quatro semanas.
- Alternância entre caminhada e corrida.
- Dicas para quem está começando.

### Nível 2 – Intermediário (10 km)
- Treinos de velocidade.
- Treinos de ritmo constante.
- Treinos longos para ganho de resistência.

### Nível 3 – Avançado (21 km / 42 km)
- Estratégias para provas de longa distância.
- Orientações sobre preparação para provas.
- Formulário para definição de metas.

## ♿ Aplicação dos Conceitos de IHC

O projeto foi desenvolvido considerando quatro conceitos principais:

**1. Usabilidade**

- Menu de navegação simples e intuitivo.
- Organização dos conteúdos por níveis.
- Botões de fácil identificação.
- Navegação entre todas as páginas.

**2. Experiência do Usuário (UX)**

- Organização progressiva dos treinamentos.
- Identificação da página atual.
- Indicação do nível de treinamento.
- Interface limpa e objetiva.

**3. Acessibilidade**

- Botões para aumentar e diminuir o tamanho da fonte.
- Opção de alto contraste.
- Link para pular diretamente ao conteúdo principal.
- Identificação dos elementos para leitores de tela.
- Destaque visual para navegação pelo teclado.

**4. Responsividade**

- Layout adaptável para computadores, tablets e celulares.
- Utilização de CSS Grid e Flexbox.
- Menu adaptado para telas menores.
- Tabelas com rolagem horizontal em dispositivos móveis.

## 🎨 Decisões de Design

Foi escolhida uma identidade visual minimalista, utilizando principalmente tons de azul, branco e cinza.

As escolhas foram realizadas para proporcionar:
- Boa legibilidade.
- Facilidade de navegação.
- Organização das informações.
- Redução de elementos visuais desnecessários.
- Melhor experiência em diferentes dispositivos.
